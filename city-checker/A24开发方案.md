## 七、附录：Gazebo 地图导入参考步骤

```bash
# 1. 创建模型目录
mkdir -p ~/.gazebo/models

# 2. 复制模型文件到Gazebo模型目录
cp -r 地图与模型/extracted/* ~/.gazebo/models/

# 3. 设置环境变量
echo 'export GAZEBO_MODEL_PATH=$HOME/.gazebo/models:$GAZEBO_MODEL_PATH' >> ~/.bashrc
source ~/.bashrc

# 4. 验证导入
gazebo  # 在Insert标签页中应能看到导入的模型
```
